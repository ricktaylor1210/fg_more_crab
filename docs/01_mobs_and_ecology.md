# 生物与生态设计

本文件描述所有螃蟹相关实体的设计意图、行为逻辑与掉落。

---

## 1. 基础螃蟹类

### 1.1 普通螃蟹（MOB-CRAB-01）

- **定位**：前期生态 & 食物来源
- **生物群系**：海滩、浅海岸
- **属性（建议值）**： 
  - HP：10
  - 攻击：2
- **行为**： 
  - 在沙滩 / 浅水区域随机游走
  - 被攻击时优先逃跑，多次受击后成群反击
- **掉落**： 
  - 生蟹肉
  - 蟹壳碎片（用于基础蟹壳装备合成）

---

### 1.2 矿物螃蟹（MOB-CRAB-02）

- **定位**：矿洞中的“行走矿藏”
- **生物群系**：洞穴、矿洞、下界矿道
- **当前实体**：
  - `fg:mineral_crab_coal`
  - `fg:mineral_crab_copper`
  - `fg:mineral_crab_iron`
  - `fg:mineral_crab_gold`
  - `fg:mineral_crab_redstone`
  - `fg:mineral_crab_lapis_lazuli`
  - `fg:mineral_crab_emerald`
  - `fg:mineral_crab_diamond`
  - `fg:mineral_crab_quartz`
- **核心机制**： 
  - 当前落地为 9 个独立矿物实体，不再依赖运行时 `OreType` 子类型。
  - 服务端 Python 会扫描匹配矿石，确认矿石旁有可站立接近点，推动矿物蟹靠近后真实删除矿石方块。
  - 吃矿后按矿种触发短时强化：煤偏速度，铜 / 铁 / 钻晶 / 石英偏真实减伤和稳定性，金 / 红石偏攻击节奏，青金偏追踪，绿宝偏逃逸和恢复。
- **掉落**： 
  - 对应矿物
  - 蟹壳碎片

---

### 1.3 海盗螃蟹（MOB-CRAB-03）

- **定位**：高价值“捣乱者”
- **生物群系**：海岸线、沉船附近、海盗藏身处结构
- **属性（建议值）**： 
  - HP：16
  - 攻击：3
- **核心 AI 行为**： 
  1. 进入玩家 5 格范围后，尝试从玩家背包中寻找“高价值物品”（绿宝石、金锭、钻石等）。
  2. 若成功找到： 
     - 从背包中偷取 1 个物品 → 记录到 `stolenItem`
     - 切换为“逃跑模式”，优先往水域或海盗结构方向逃跑
  3. 若被击杀： 
     - 必定掉落 `stolenItem`
     - 当前按职业额外掉落：水手偏金粒和生蟹肉，船长偏金锭 / 绿宝石 / 生蟹肉，炮手偏火药 / 铁粒 / 蟹壳碎片。
     - 藏宝图采用混合口径：击杀少量直掉，主要仍来自小型藏身处和 Boss 结构宝箱。
- **用途**： 
  - 丰富海岸玩法，提供小型“追捕事件”
  - 与海盗蟹结构、海洋探索联动

## 2. 驯服与负重螃蟹

### 2.1 驯服螃蟹（MOB-CRAB-04）

- **类型**：Tamable 宠物
- **来源**：由普通螃蟹驯服而来
- **驯服道具**： 
  - 不使用蟹肉棒、蟹肉寿司、蟹黄汤等自定义 food
  - 驯服入口使用非料理类诱饵，具体按螃蟹变体区分
- **行为**： 
  - 跟随主人
  - 攻击主人攻击的目标
  - 右键切换“跟随 / 待命”

详细驯服逻辑见：`docs/04_systems_and_mechanics.md#驯服系统`

---

### 2.2 负重螃蟹（MOB-CRAB-05）

- **类型**：宠物 + 功能生物
- **前置**：已驯服螃蟹 + 蟹壳背包物品
- **核心机制**： 
  - Shift + 手持「蟹壳背包」右键 → 给螃蟹装备背包
  - 已装备背包后 Shift + 右键 → 打开 27 格原生容器
  - 已装备背包后 Shift + 手持剪刀右键 → 容器为空时卸下背包，并掉落背包物品供玩家回收
- **当前实机口径**：
  - 已接入背包物品、配方、装备 / 卸下、掉落回收、27 格原生容器、主人限制和背包模型显示
  - 已确认可装备、可打开 27 格容器、可放置物品，标题不再显示“未知”
  - 卸下前会检查容器库存，非空或读取失败时阻止卸下，避免物品丢失
  - 区块卸载、死亡掉落和维度切换后的长线保存仍需继续回归
- **后续背包容量目标**：
  - 初始设计曾考虑 9 / 18 / 27 格分级；当前 Agent 式 `container` 实机口径按 27 格记录，后续分级另做扩展

详细实现与 UI 说明见：`docs/04_systems_and_mechanics.md#负重螃蟹背包系统`

## 3. Boss 总览（详细见 Boss 文档）

五大 Boss 简述，本文件只做索引，详细数值与阶段行为见：`docs/06_worldgen_and_bosses.md`。

当前 Boss 不再通过自然生成规则或发布包生成蛋进入生存流程，入口限定为服务端脚本放置的巢穴 / 神庙结构；5 个展示级 `.mcstructure` 资源、P2/P3 场地机制、首轮结构宝箱、3 天 Boss 重刷、Boss 核心、套装和武器主动技能均已接入 TASK-01~15 主线静态闭环，仍需游戏内验证结构放置、盾牌 / 装备手感、Boss 技能和数值平衡。

- 熔岩蟹王（MOB-BOSS-01）
  - 场景：地狱 / 岩浆湖
  - 特性：火焰免疫，熔岩喷射、岩浆雨、爆裂地面
  - 当前掉落与装备链：熔岩蟹王核心，用于炽焰壳甲和熔岩战斧基础配方
- 寒霜蟹王（MOB-BOSS-02）
  - 场景：冰原 / 雪山冰洞
  - 特性：冰刺、冻气吐息、反伤护盾
  - 当前掉落与装备链：冰壳蟹王核心，用于寒霜壳甲和寒晶蟹矛基础配方
- 毒沼蟹王（MOB-BOSS-03）
  - 场景：沼泽毒池中心
  - 特性：毒雾、毒泥陷阱、召唤毒蟹，毒池回血
  - 当前掉落与装备链：毒沼蟹王核心，用于毒沼壳甲和沼毒钳刃基础配方
- 潮汐蟹王（MOB-BOSS-04）
  - 场景：远洋海底祭坛
  - 特性：水流冲击、泡泡牢笼、潮汐爆发
  - 当前掉落与装备链：潮汐蟹王核心，用于潮汐壳甲和潮击三叉钳基础配方
- 循声蟹守卫（MOB-BOSS-05）
  - 场景：深海深渊蟹神庙
  - 特性：震动感知、音波冲击、黑暗领域，类似 Warden 的怒气机制
  - 当前掉落与装备链：回音守卫蟹王核心，用于回声壳甲和震荡钳刃基础配方
