# 生物与生态设计

本文件描述所有螃蟹相关实体的设计意图、行为逻辑与掉落。

---

## 1. 基础螃蟹类

### 1.1 普通螃蟹（MOB-CRAB-01）

- **定位**：前期生态 & 食物来源
- **生物群系**：海滩、浅海岸
- **属性（建议值）**： 
  - HP：10
  - 攻击：2
- **行为**： 
  - 在沙滩 / 浅水区域随机游走
  - 被攻击时优先逃跑，多次受击后成群反击
- **掉落**： 
  - 生蟹肉
  - 蟹壳碎片（用于基础蟹壳装备合成）

---

### 1.2 矿物螃蟹（MOB-CRAB-02）

- **定位**：矿洞中的“行走矿藏”
- **生物群系**：洞穴、矿洞
- **属性（建议值）**： 
  - HP：20
  - 攻击：4
- **核心机制**： 
  - 拥有 `OreType`（煤/铁/金/钻/绿宝石等）
  - 靠近矿石方块时，有概率： 
    - “吃掉”矿石方块 → 自身获得短时护甲 Buff
- **掉落**： 
  - 对应矿物（根据 OreType）
  - 蟹壳

---

### 1.3 海盗螃蟹（MOB-CRAB-03）

- **定位**：高价值“捣乱者”
- **生物群系**：海岸线、沉船附近、海盗藏身处结构
- **属性（建议值）**： 
  - HP：16
  - 攻击：3
- **核心 AI 行为**： 
  1. 进入玩家 5 格范围后，尝试从玩家背包中寻找“高价值物品”（绿宝石、金锭、钻石等）。
  2. 若成功找到： 
     - 从背包中偷取 1 个物品 → 记录到 `stolenItem`
     - 切换为“逃跑模式”，优先往水域或海盗结构方向逃跑
  3. 若被击杀： 
     - 必定掉落 `stolenItem`
     - 额外掉落：金币、藏宝图、少量蟹壳
- **用途**： 
  - 丰富海岸玩法，提供小型“追捕事件”
  - 与海盗蟹结构、海洋探索联动

## 2. 驯服与负重螃蟹

### 2.1 驯服螃蟹（MOB-CRAB-04）

- **类型**：Tamable 宠物
- **来源**：由普通螃蟹驯服而来
- **驯服道具**： 
  - 蟹肉棒：中等成功率
  - 蟹肉寿司 / 蟹黄汤：高成功率
- **行为**： 
  - 跟随主人
  - 攻击主人攻击的目标
  - 右键切换“跟随 / 待命”

详细驯服逻辑见：`docs/02_systems_and_mechanics.md#驯服系统`

---

### 2.2 负重螃蟹（MOB-CRAB-05）

- **类型**：宠物 + 功能生物
- **前置**：已驯服螃蟹 + 蟹壳背包物品
- **核心机制**： 
  - Shift + 手持「蟹壳背包」右键 → 给螃蟹装备背包
  - 再次 Shift + 右键（空手） → 打开螃蟹背包界面
  - 死亡时： 
    - 掉落背包物品
    - 背包内所有物品掉落世界或优先给主人
- **背包容量**： 
  - 初始设计：9 格 / 18 格 / 27 格，可按材料分等级扩展

详细实现与 UI 说明见：`docs/02_systems_and_mechanics.md#负重螃蟹背包系统`

## 3. Boss 总览（详细见 Boss 文档）

五大 Boss 简述，本文件只做索引，详细数值与阶段行为见：`docs/04_worldgen_and_bosses.md`。

- 熔岩蟹王（MOB-BOSS-01）
  - 场景：地狱 / 岩浆湖
  - 特性：火焰免疫，熔岩喷射、岩浆雨、爆裂地面
  - 掉落：熔壳碎片、岩浆心核、炽焰壳甲图样、熔爪巨钳
- 寒霜蟹王（MOB-BOSS-02）
  - 场景：冰原 / 雪山冰洞
  - 特性：冰刺、冻气吐息、反伤护盾
  - 掉落：霜甲核心、冰晶碎壳、寒霜壳甲图样、寒晶蟹矛
- 毒沼蟹王（MOB-BOSS-03）
  - 场景：沼泽毒池中心
  - 特性：毒雾、毒泥陷阱、召唤毒蟹，毒池回血
  - 掉落：毒囊、腐沼壳结晶、腐沼壳甲图样、沼毒钳刃
- 潮汐蟹王（MOB-BOSS-04）
  - 场景：远洋海底祭坛
  - 特性：水流冲击、泡泡牢笼、潮汐爆发
  - 掉落：潮汐之心、水晶壳碎片、潮汐壳甲图样、潮击三叉钳
- 循声蟹守卫（MOB-BOSS-05）
  - 场景：深海深渊蟹神庙
  - 特性：震动感知、音波冲击、黑暗领域，类似 Warden 的怒气机制
  - 掉落：声波之核、深渊碎壳、回声壳甲图样、震荡钳刃
