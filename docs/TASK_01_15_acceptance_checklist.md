# TASK-01~15 集中验收清单

## 验收口径

本轮只验收 TASK-01~15 主线闭环：

- 普通生态螃蟹、矿物螃蟹、海盗螃蟹、捕蟹笼、驯服、负重背包、料理、基础装备、5 个 Boss、Boss 结构、Boss 掉落和 Boss 装备。
- 不把蟹卵养殖、潮汐入侵、元素盾牌、结构谜题、复杂神庙迷宫和深海终局事件纳入当前完成目标。
- 背包继续保留 27 格 `container` 第一方案。基础打开、放置物品、标题和卸下保护已实机可用；死亡、维度切换、区块卸载和多人边界继续记录，不自动切到 `horse + is_chested`。

## 验收顺序

1. 启动与加载
   - 行为包和资源包加载无 assert、无 recipe result malformed、无实体 / 物品 / 资源缺失报错。
   - 关注日志关键字：`fg_more_crab`、`validation.`、`recipe`、`entity`、`loot`、`PlaceStructure`。

2. TASK-01~03 生物主链
   - 7 个普通生态蟹能自然出现或通过调试入口生成，掉落和动画正常。
   - 9 个矿物蟹按类型环境出现，能靠近对应矿石并吃矿触发类型化 Buff。
   - 3 个海盗蟹能偷窃、携物逃跑、击杀返还，逃跑状态能回落。

3. TASK-04~06 交互系统
   - 驯服只对主人显示并执行跟随 / 待命、背包装备、背包卸下等交互。
   - 捕蟹笼只能通过物品放置入口进入世界；不可自然生成或刷怪蛋生存入口展示。
   - 捕蟹笼可放置 / 替换诱饵，成熟后可收获，水中成熟时浮起，陆地捕获概率明显降低。

4. TASK-05 负重背包重点
   - 已驯服且是主人：Shift+空手 / 非剪刀右键已装备背包蟹，27 格 `container` 应能打开，窗口标题显示螃蟹默认名或玩家自定义名。
   - 非主人：继续验证容器是否被限制，交互文本不应误导。
   - 背包放入物品后：Shift+手持剪刀右键应阻止卸下，烟雾提示出现，物品不丢失。
   - 死亡、维度切换、区块卸载后：记录容器是否保留和是否丢物。
   - 如果后续长线边界异常，只记录为兼容问题；本轮不自动切换到 horse 容器方案。

5. TASK-07~08 料理与基础装备
   - 所有料理可获取、可食用，效果和饱食度按文档记录。
   - 蟹壳护甲可装备，防御、耐久、装备栏表现正常。
   - 蟹壳盾牌可副手持有，激活盾牌时有格挡表现；正面抵挡、冷却和耐久写回需要重点记录。

6. TASK-09~14 Boss 和结构
   - 5 个 Boss 不通过自然生成进入生存流程。
   - 5 个 Boss 发布包不提供生成蛋入口，仍可用 `/summon` 做开发验证。
   - 5 个 `.mcstructure` 能由脚本放置，结构不缺块、不出现明显错位。
   - 同一巢穴 bucket 的结构和宝箱只生成一次；Boss 击杀后按 3 个 Minecraft 天重刷，已有 Boss / 战斗中不重刷。
   - 宝箱 loot table 生效；Boss 核心只由 Boss 击杀掉落，不从结构宝箱直接获得。
   - P2/P3 技能能触发，临时方块在到期后恢复，Boss 战中退出 / 死亡不留下明显残留状态。

7. TASK-15 Boss 装备
   - 5 套 Boss 护甲完整套装效果和受击反制正常。
   - 5 把 Boss 武器命中特效正常。
   - 右键主动技能均可触发，统一 12 秒冷却，消耗耐久，粒子和音效命令不报错。

8. 长时间稳定性
   - 单人至少连续运行 30 分钟，多人至少覆盖一次 Boss 战和一次背包交互。
   - 重点观察重复结构生成、区块卸载、Boss 战中死亡 / 退出、临时方块恢复和后台日志增长。

- 世界类型 / 维度 / 坐标：
- 触发步骤：
- 预期表现：
- 实际表现：
- 相关实体 / 物品 / 结构 ID：
- 日志片段，尤其是 `validation.` 开头的脚本警告：
- 判断类型：兼容问题 / 资源引用问题 / 数值平衡问题 / 文档问题。
- 当前处理：本轮修复 / 记录到平衡回调 / 记录到后续扩展。

## 通过标准

- 静态检查：`python -B tools\run_checks.py` 全部通过，`git diff --check` 无实际错误。
- 加载检查：行为包和资源包无阻断加载错误。
- 主线闭环：从普通生态、材料、料理 / 装备、Boss 结构、Boss 击杀、Boss 装备制作到主动技能使用，均可在游戏内走通。
- 兼容记录：背包 `container`、自定义盾牌、`PlaceStructure`、宝箱 loot table、音效 / 粒子命令、临时方块恢复均有实机结论。
- 已知限制：若仍有引擎兼容问题，必须在文档中标为已知限制，而不是写成已完全验收。
