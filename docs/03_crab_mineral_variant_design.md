# 矿物螃蟹类型设计（基于当前资源包贴图）

## 1. 设计目标

矿物螃蟹在 spec 中的定位非常明确：

- 洞穴 / 矿洞中的“行走矿藏”
- 拥有 OreType
- 靠近矿石时可以吃矿，随后获得强化
- 击杀后掉落对应矿物与蟹壳

因此，矿物螃蟹的不同类型应该直接围绕 原版矿物系统 来设计，而不是只做换色皮肤。它们要承担三个职责：

1. 让玩家一眼就能知道“这只蟹值什么资源”
2. 让洞穴探索多一个可追踪、可狩猎、可规避的动态目标
3. 给中前期资源获取增加少量事件感，但不破坏原版采矿主循环

## 3. 设计原则

### 3.1 一个矿物实体，不做九个独立实体

推荐最终架构：

- crab_mineral
- ore_type：九种矿物类型
- fed_state：是否刚吃过矿
- burrow_state：是否处于警觉/潜伏/逃逸
- tier：普通 / 稀有 / 特殊维度

这样可以显著降低维护成本，也更符合 spec 中的 OreType 设定。

### 3.2 矿物型的差异要大于普通型，但仍然服从原版世界规则

矿物螃蟹是功能性更强的生物，所以差异可以比普通螃蟹明显一些，但必须遵守原版世界的逻辑：

- 煤、铜、铁：常见，承担玩家第一次见到矿物螃蟹的体验
- 金、红石、青金：中层与深层功能型
- 绿宝石、钻石：稀有高价值型
- 石英：特殊维度型，不强行塞进主世界

### 3.3 吃矿强化必须“简单可读”

不要给矿物蟹做一堆难记的状态。最佳方式是：

- 每种矿物蟹只有 一个核心强化方向
- 玩家看到颜色就能大致猜到它吃矿后会变成什么样
- 强化时间短，鼓励“观察后再出手”

## 4. 九种矿物螃蟹的最终设计

### 4.1 煤矿蟹 coal

定位：最常见的矿物螃蟹，作为矿洞教程型。  
推荐层级：浅层洞穴、中层洞穴。  
稀有度：高（常见）。

#### 行为特征

- 生成频率最高
- 更喜欢在昏暗处活动
- 受惊后优先逃到阴影或石头边

#### 吃矿强化

- 吃掉煤矿后进入“躁动”状态
- 移动速度提高
- 身上可加少量黑灰粒子，便于玩家识别它刚吃过矿

#### 掉落偏向

- 煤
- 蟹壳
- 少量经验

#### 设计价值

- 让玩家第一次理解“矿物蟹会吃矿，并且吃完会变强”

### 4.2 铜矿蟹 copper

定位：中低层常见资源型，偏耐久和工艺感。  
推荐层级：普通洞穴、滴水石洞。  
稀有度：中高。

#### 行为特征

- 喜欢靠近大面积裸露岩壁
- 巡逻感更强，不一定总是逃跑
- 适合作为“看起来有一点点硬”的矿物蟹

#### 吃矿强化

- 吃掉铜矿后获得短时护甲提升
- 击退抗性略增
- 行为上显得更“沉”，不容易被随手打退

#### 掉落偏向

- 铜锭/铜矿物材料（按你的版本实际资源结构决定）
- 蟹壳

#### 设计价值

- 承接煤矿蟹与铁矿蟹之间的进阶感
- 很适合做成“矿物壳层明显”的视觉代表

### 4.3 铁矿蟹 iron

定位：最标准的中期矿物蟹。  
推荐层级：洞穴、中深层矿道。  
稀有度：中。

#### 行为特征

- 移动较稳
- 警戒后不一定立刻逃跑，可能先横移观察
- 是矿物螃蟹里最适合做“正面交战模板”的类型

#### 吃矿强化

- 吃掉铁矿后获得明显护甲强化
- 受击时更能扛
- 非常符合“铁壳”直觉

#### 掉落偏向

- 铁相关掉落
- 蟹壳
- 壳类材料概率略高

#### 设计价值

- 这是矿物蟹平衡的基准线
- 你后续做金、钻石、石英时，都应该拿它做中轴比较

### 4.4 金矿蟹 gold

定位：中高价值、但不以硬度取胜的矿物型。  
推荐层级：深层、恶地矿区、特殊矿道。  
稀有度：中低。

#### 行为特征

- 比铁矿蟹更灵活
- 警戒后更容易快速横移或撤退
- 看起来“贵”，但不应该表现成坦克

#### 吃矿强化

- 吃掉金矿后，攻击频率或行动节奏提升
- 可以理解为“金壳活性化”
- 强化方向是灵巧，不是硬度

#### 掉落偏向

- 金相关掉落
- 蟹壳
- 稀有战利品权重可略高

#### 设计价值

- 给玩家一种“这只值钱，但不一定好打”的感受
- 形成和铁矿蟹的明确对照：铁更稳，金更快

### 4.5 红石蟹 redstone

定位：深层功能型矿物蟹。  
推荐层级：深层洞穴、板岩层附近。  
稀有度：中低。

#### 行为特征

- 警觉范围更大
- 容易更早发现玩家
- 可以在移动或锁敌时附带微弱红光/粒子感

#### 吃矿强化

- 吃掉红石矿后进入“激发”状态
- 攻击前摇缩短，追击更积极
- 可理解为被红石能量驱动

#### 掉落偏向

- 红石
- 蟹壳
- 少量经验

#### 设计价值

- 非常适合做“深层矿洞里比你先发现你”的那种压力源
- 与原版红石的“通电、激活、快速响应”语义一致

### 4.6 青金蟹 lapis

定位：深层但相对冷静的功能型矿物蟹。  
推荐层级：深层洞穴、水边矿道。  
稀有度：中低。

#### 行为特征

- 不一定主动追人
- 更偏“守着矿点活动”
- 可以做成在洞穴水边更常见

#### 吃矿强化

- 吃掉青金石矿后，警戒视野提升或索敌持续时间变长
- 不一定变得更快，但会变得更难甩开

#### 掉落偏向

- 青金石
- 蟹壳
- 经验略高于煤/红石类型

#### 设计价值

- 作为“不是纯战斗，但很烦人”的洞穴生物
- 同时兼顾附魔/经验联想，但不要直接做成经验怪

### 4.7 绿宝蟹 emerald

定位：高价值稀有型。  
推荐层级：山地矿区、山体洞穴。  
稀有度：低（稀有）。

#### 行为特征

- 生成条件更苛刻
- 优先逃跑，不轻易站撸
- 看到玩家时更容易拉开距离

#### 吃矿强化

- 吃掉绿宝石矿后获得短时恢复或更强逃逸能力
- 不强调正面对抗
- 强调“高价值猎物”体验

#### 掉落偏向

- 绿宝石
- 蟹壳
- 高价值掉落权重更高

#### 设计价值

- 它应该像矿洞里的“会跑的珍贵资源”
- 玩家的情绪应该是“追得上就赚”，而不是“又来一个战斗怪”

### 4.8 钻晶蟹 diamond

定位：顶级稀有矿物螃蟹。  
推荐层级：深板岩层、极深洞穴。  
稀有度：极低。

#### 行为特征

- 天然护甲最高
- 速度不快，但很难被快速击杀
- 更适合作为“深层惊喜事件”

#### 吃矿强化

- 吃掉钻石矿后获得最强护甲强化
- 可附带短时击退抗性
- 强化期很明显，提醒玩家别无脑硬打

#### 掉落偏向

- 钻石
- 蟹壳
- 稀有壳类素材

#### 设计价值

- 作为 V1.0 矿物螃蟹体系的顶点
- 必须稀有，否则会破坏原版采矿节奏

### 4.9 石英蟹 quartz

定位：下界专属 / 特殊维度矿物型。  
推荐层级：下界洞穴、下界矿道。  
稀有度：中低（仅限下界）。

#### 行为特征

- 在下界地形中活动
- 不怕热源
- 行为上可更偏主动巡逻

#### 吃矿强化

- 吃掉下界石英矿后获得短时恢复或击退能力
- 表现为“晶化强化”，而不是金属硬化

#### 掉落偏向

- 石英
- 蟹壳
- 少量下界相关素材（如果后续扩展）

#### 设计价值

- 资源包已经有贴图，所以最好保留设计位
- 但 不建议把它硬塞进 V1.0 主世界洞穴循环
- 更合理的方式是： 
  - 作为下界分支内容
  - 或作为高级捕蟹笼 / 后续扩展解锁内容

## 5. 推荐分层与出现顺序

为了保证 Minecraft 感和采矿节奏，建议矿物蟹按层级推进：

### 5.1 低压入门层

- 煤矿蟹
- 铜矿蟹
- 铁矿蟹

作用：

- 教玩家认识矿物蟹
- 不直接给太大资源刺激
- 也不会让前期洞穴压力失控

### 5.2 深层功能层

- 金矿蟹
- 红石蟹
- 青金蟹

作用：

- 提升洞穴探索的事件性
- 开始让不同矿蟹具备明显不同的追击/观察/机动风格

### 5.3 稀有价值层

- 绿宝蟹
- 钻晶蟹

作用：

- 提供追猎目标
- 强化“这不是普通怪，而是动态矿藏”的感觉

### 5.4 特殊维度层

- 石英蟹

作用：

- 不挤占主世界流程
- 给后续版本留扩展空间

## 6. 吃矿强化的统一框架

为了方便实现，建议所有矿物蟹共享同一套状态机：

```text
idle -> detect_ore -> move_to_ore -> consume_ore -> fed_buff_active -> buff_end
```

### 统一字段建议

```text
entity: crab_mineral
- ore_type: coal / copper / iron / gold / redstone / lapis / emerald / diamond / quartz
- fed_buff_timer: int
- target_ore_block: block_pos
- temperament: cautious / neutral / hunter
```

### 统一规则建议

- 只有在附近存在匹配矿石时才触发吃矿行为
- 吃矿后短时间强化
- 强化结束后恢复普通状态
- 同一只矿物蟹短时间内不应连续吃矿，避免刷屏和性能问题

## 7. 推荐的 Buff 对照表

| 矿物类型 | 强化方向       | 玩家直觉    |
|------|------------|---------|
| 煤    | 速度提升       | 像被燃料点燃  |
| 铜    | 轻度护甲 + 稳定性 | 铜壳更厚、更稳 |
| 铁    | 明显护甲提升     | 铁壳更硬    |
| 金    | 攻击/行动节奏加快  | 金壳更灵活   |
| 红石   | 索敌更快、攻击更频繁 | 被“通电激活” |
| 青金   | 视野/追踪时间提升  | 更聪明、更专注 |
| 绿宝石  | 逃逸/恢复能力提升  | 珍贵且难抓   |
| 钻石   | 高护甲 + 击退抗性 | 顶级硬壳    |
| 石英   | 晶化恢复或击退能力  | 下界晶体强化  |

## 8. 掉落与平衡边界

矿物蟹很容易破坏平衡，所以掉落要守住下面这些边界：

### 应该做的

- 掉落与类型强相关
- 掉落数量略有波动
- 高价值型稀有生成
- 吃矿强化会让击杀门槛上升

### 不应该做的

- 掉落量稳定高于直接挖矿
- 大量替代原版采矿效率
- 让钻石蟹成为刷钻主流手段
- 让石英蟹在主世界随便出现

推荐原则：

- 击杀矿物蟹是一种“动态补充”
- 不是“比挖矿更优的主路径”

## 9. 技术落地建议

### 9.1 贴图映射建议

```text
coal     -> fg_mineral_crab_coal
copper   -> fg_mineral_crab_copper
iron     -> fg_mineral_crab_iron
gold     -> fg_mineral_crab_gold
redstone -> fg_mineral_crab_redstone
lapis    -> fg_mineral_crab_lapis_lazuli
emerald  -> fg_mineral_crab_emerald
diamond  -> fg_mineral_crab_diamond
quartz   -> fg_mineral_crab_quartz
```

### 9.2 生成实现建议

- 不做 9 个实体文件
- 优先做 1 个 crab_mineral + 1 个 ore_type
- 生成表里按群系 / 高度 / 维度设置不同权重
- V1.0 先做： 
  - 煤
  - 铜
  - 铁
  - 金
  - 红石
  - 青金
  - 绿宝石
  - 钻石
- 石英蟹可留作 V1.0.5 或 V1.1 前置扩展

### 9.3 捕蟹笼联动建议

后续高级捕蟹笼可以和矿物蟹联动，但不要一开始就全开放。

建议：

- 普通捕蟹笼：不出矿物蟹
- 铁/金捕蟹笼：少概率出煤/铜/铁矿蟹
- 更高级捕蟹笼：才允许金、红石、青金、绿宝、钻晶
- 石英蟹只在下界或特殊陷阱里解锁

---

## 10. 最终结论

矿物螃蟹最合理的设计方式是：

- 一个实体
- 九种 ore_type 子类型
- 每种矿物对应一种简单明确的强化方向
- 按原版资源分层控制生成与价值

这样能最大化利用你现有资源包里的矿物贴图，同时保持 Minecraft 的原版语感：玩家看到颜色就能读懂资源价值，看到行为就能猜到风险等级。
