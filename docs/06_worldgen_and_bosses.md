# 世界生成与 Boss 设计

---

## 1. 结构总览

### 1.1 蟹穴 / 蟹窝（CRAB-STRUCT-01）

- 地点：沙滩
- 内容： 
  - 小型坑洞结构
  - 刷普通螃蟹
  - 小箱子（蟹壳、蟹肉、基础食物）

### 1.2 海盗蟹藏身处（CRAB-STRUCT-02）

- 地点：海岸 / 半埋沉船附近
- 内容： 
  - 生成海盗螃蟹
  - 宝箱：金币、藏宝图、高价值战利品

### 1.3 四大蟹王巢穴（CRAB-STRUCT-03）

- 熔岩蟹巢：地狱岩浆洞
- 寒霜巢穴：冰原冰洞
- 毒沼祭坛：沼泽中心石台 + 毒池
- 潮汐祭坛：海底石阵 + 珊瑚装饰

每个巢穴负责刷新对应 Boss，内部含有对应主题方块与小战利品箱。

### 1.4 深渊蟹神庙（CRAB-STRUCT-04）

- 地点：远海深处 / 深海沟
- 内容： 
  - 复杂迷宫式或祭坛式结构
  - 中心区域用于召唤 / 刷新循声蟹守卫
  - 有少量高价值宝箱（但不鼓励刷 Boss 以刷物资）

## 2. Boss 阶段设计（摘要）

详细阶段表已在 Excel 与 `2-Boss阶段` 表中，这里只做概述。

### 2.1 熔岩蟹王（MOB-BOSS-01）

- 阶段 1（100%~70%）：  
  近战钳击 + 小范围熔岩喷射，偶发地面爆裂
- 阶段 2（70%~40%）：  
  定期施放岩浆雨，熔岩喷射频率明显提升
- 阶段 3（40%~0%）：  
  制造岩浆池周期回血，爆裂范围加大

### 2.2 寒霜蟹王（MOB-BOSS-02）

- 阶段 1：冰刺 + 少量冻气吐息
- 阶段 2：大范围冻气减速 + 高频冰刺
- 阶段 3：地面大面积结冰 + 反伤护盾

### 2.3 毒沼蟹王（MOB-BOSS-03）

- 阶段 1：单体毒液喷吐 + 少量毒泥
- 阶段 2：大面积毒泥区 + 持续毒雾 + 少量毒蟹
- 阶段 3：回到毒池中心持续回血 + 大量召唤毒蟹

### 2.4 潮汐蟹王（MOB-BOSS-04）

- 阶段 1：水流冲击 + 少量泡泡牢笼
- 阶段 2：提高泡泡牢笼频率 + 潮汐爆发
- 阶段 3：多段潮汐爆发 + 水位变化，需要频繁调整站位

### 2.5 循声蟹守卫（MOB-BOSS-05）

- 阶段 1：感知阶段，缓慢移动，以近战为主
- 阶段 2：频繁释放音波冲击 + 周期黑暗效果
- 阶段 3：深渊声域：持续黑暗 + 声波领域伤害 + 地面震荡

## 3. 环境与对策

- 熔岩蟹王：推荐准备抗火药水、火焰抗性装备
- 寒霜蟹王：火属性武器、避免长时间站在冰面
- 毒沼蟹王：牛奶 / 抗性药水、保持移动避免长时间停留毒泥
- 潮汐蟹王：水下呼吸 + 抗性药水、潮汐壳系装备尤佳
- 循声蟹守卫：尽量控制噪音（少跳、少挖、多潜行），利用假声干扰
