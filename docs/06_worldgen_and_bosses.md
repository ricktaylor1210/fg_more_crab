# 世界生成与 Boss 设计

---

## 1. 结构总览

### 1.1 蟹穴 / 蟹窝（CRAB-STRUCT-01）

- 地点：沙滩
- 内容： 
  - 小型坑洞结构
  - 刷普通螃蟹
  - 小箱子（蟹壳、蟹肉、基础食物）

### 1.2 海盗蟹藏身处（CRAB-STRUCT-02）

- 地点：海岸 / 半埋沉船附近
- 内容： 
  - 生成海盗螃蟹
  - 宝箱：金币、藏宝图、高价值战利品

当前落地：

- 服务端脚本会扫描水边、沙砾地、木质残骸、箱子和木桶，作为海盗蟹补刷锚点。
- 如果附近没有现成残骸，脚本会在合适海岸低概率生成一个小型藏身处场景。
- 小型藏身处由木板、木桶、箱子和少量掉落物组成，并会额外刷出 1-2 只海盗蟹。
- 正式大型沉船结构和更复杂的沉船联动可以作为后续扩展。

### 1.3 四大蟹王巢穴（CRAB-STRUCT-03）

- 熔岩蟹巢：地狱岩浆洞
- 寒霜巢穴：冰原冰洞
- 毒沼祭坛：沼泽中心石台 + 毒池
- 潮汐祭坛：海底石阵 + 珊瑚装饰

每个巢穴负责刷新对应 Boss，内部含有对应主题方块与小战利品箱。

当前结构主线落地：

- 服务端脚本会按玩家附近环境低频扫描并放置展示级 `.mcstructure` 巢穴资源，再刷出对应 Boss、补给宝箱和非核心奖励。
- 每个巢穴 bucket 的结构和宝箱只生成一次；之后只重刷 Boss，不重复刷结构和补给箱。
- Boss 重刷间隔为 3 个 Minecraft 天，按当前项目 30 tick / 秒口径换算为 108000 个脚本 tick；已有 Boss 存在或战斗中时不会重刷。
- 5 个 Boss 自然生成规则已禁用，生存入口限定为脚本巢穴 / 神庙结构；发布包关闭生成蛋入口，保留 `/summon` / 开发入口用于调试。
- 结构文件位于行为包 `structures/fg_more_crab/`，命名为 `fg_more_crab:boss_lair_lava`、`fg_more_crab:boss_lair_ice`、`fg_more_crab:boss_lair_poisonous_swamp`、`fg_more_crab:boss_lair_tidal` 和 `fg_more_crab:boss_temple_sound_guard`。
- 结构已从基础地台升级为展示级圆形 / 殿堂布局，包含外环、路线、祭坛、机关区、装饰柱、主题视觉和 3 个补给箱点位。
- 熔岩蟹巢绑定地狱岩 / 玄武岩 / 黑石环境；当前网易环境中的巢穴维度 ID 按 `0` 处理。
- 寒霜巢穴绑定雪、冰、浮冰及寒冷地表环境。
- 毒沼祭坛绑定泥、草、土、黏土等沼泽 / 潮湿地表。
- 潮汐祭坛绑定沙、砾石、黏土等水岸 / 海岸环境。
- 当前结构只负责地形、祭坛、路径和主题视觉；Boss 实体、掉落和首轮宝箱由脚本放置，避免二进制结构里塞复杂实体数据。
- Boss 核心由 Boss 实体直掉；结构宝箱提供补给、主题材料、蟹壳碎片、蟹钳和藏宝图，不直接给核心。
- 结构谜题、终局事件和大型沉船 / 神庙迷宫仍属于后续扩展，不纳入本轮 TASK-01~15 主线。

### 1.4 深渊蟹神庙（CRAB-STRUCT-04）

- 地点：远海深处 / 深海沟
- 内容： 
  - 复杂迷宫式或祭坛式结构
  - 中心区域用于召唤 / 刷新循声蟹守卫
  - 有少量高价值宝箱（但不鼓励刷 Boss 以刷物资）

当前结构主线落地：回音守卫蟹王已作为 Boss 实体、掉落、血条、阶段、脚本技能和回音神庙 `.mcstructure` 接入；回音神庙已具备展示级祭坛、路线、补给箱和声波主题机关区。复杂迷宫、震动谜题和完整深海终局事件尚未纳入本轮。

## 2. Boss 阶段设计（摘要）

详细阶段表已在 Excel 与 `2-Boss阶段` 表中，这里只做概述。

当前实现共用阶段阈值：

- 阶段 1：100% ~ 66% HP
- 阶段 2：66% ~ 33% HP，提升移动和抗击退。
- 阶段 3：33% ~ 0% HP，进一步提升压迫，并在脚本技能中获得少量回血。

### 2.1 熔岩蟹王（MOB-BOSS-01）

- 阶段 1（100%~70%）：  
  近战钳击 + 小范围熔岩喷射，偶发地面爆裂
- 阶段 2（70%~40%）：  
  定期施放岩浆雨，熔岩喷射频率明显提升
- 阶段 3（40%~0%）：  
  制造岩浆池周期回血，爆裂范围加大

当前实现：近战 + 脚本火焰主题技能，附加范围伤害、虚弱、点燃、临时火焰；P2 开始生成火池 / 爆裂地面，P3 扩展至 Boss 周边火环和熔岩地面，并召唤小怪。

### 2.2 寒霜蟹王（MOB-BOSS-02）

- 阶段 1：冰刺 + 少量冻气吐息
- 阶段 2：大范围冻气减速 + 高频冰刺
- 阶段 3：地面大面积结冰 + 反伤护盾

当前实现：近战 + 脚本冰霜主题技能，附加减速、挖掘疲劳、临时结冰地面；P2 生成冰面和冰刺，P3 给 Boss 短抗性反制窗口并召唤霜壳蟹。

### 2.3 毒沼蟹王（MOB-BOSS-03）

- 阶段 1：单体毒液喷吐 + 少量毒泥
- 阶段 2：大面积毒泥区 + 持续毒雾 + 少量毒蟹
- 阶段 3：回到毒池中心持续回血 + 大量召唤毒蟹

当前实现：近战 + 脚本毒沼主题技能，附加中毒、减速、临时黏液地形；P2 生成毒池 / 毒雾区并给 Boss 回血，P3 在 Boss 周边铺沼地并持续压迫，召唤潮苔蟹。

### 2.4 潮汐蟹王（MOB-BOSS-04）

- 阶段 1：水流冲击 + 少量泡泡牢笼
- 阶段 2：提高泡泡牢笼频率 + 潮汐爆发
- 阶段 3：多段潮汐爆发 + 水位变化，需要频繁调整站位

当前实现：近战 + 脚本潮汐主题技能，附加范围伤害、减速、位移牵引和临时水流；P2 生成水流牵引区，P3 加入水位压迫式环形水流和击退，并召唤蓝潮蟹。

### 2.5 循声蟹守卫（MOB-BOSS-05）

- 阶段 1：感知阶段，缓慢移动，以近战为主
- 阶段 2：频繁释放音波冲击 + 周期黑暗效果
- 阶段 3：深渊声域：持续黑暗 + 声波领域伤害 + 地面震荡

当前实现：近战 + 脚本声波主题技能，附加反胃、虚弱、范围声波伤害、击退；P2 生成回音领域和黑暗 / 失明压迫，非潜行目标会受到额外声波伤害，P3 在 Boss 周边释放回音冲击并召唤小怪。

## 3. 环境与对策

- 熔岩蟹王：推荐准备抗火药水、火焰抗性装备
- 寒霜蟹王：火属性武器、避免长时间站在冰面
- 毒沼蟹王：牛奶 / 抗性药水、保持移动避免长时间停留毒泥
- 潮汐蟹王：水下呼吸 + 抗性药水、潮汐壳系装备尤佳
- 循声蟹守卫：尽量控制噪音（少跳、少挖、多潜行），利用假声干扰
