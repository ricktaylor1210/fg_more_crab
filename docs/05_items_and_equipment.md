# 物品与装备设计

## 1. 食物与料理

详见 Excel 表中 FOOD-CRAB 系列，这里只列关键用途：

- **基础食物**： 
  - 蟹肉棒：基础饱食度 + 中等驯服成功率
  - 烤螃蟹：中期高饱食度
- **功能料理**： 
  - 清蒸螃蟹：回复 / 再生
  - 香辣蟹钳：力量/攻击提升
  - 蟹黄汤：再生 + 吸收，Boss 战前使用
  - 椰香蟹汤：水下呼吸，适配潮汐蟹王战
  - 蟹肉寿司：速度提升 + 高驯服成功率
  - 蟹肉炒饭 / 炒面：高饱食度 + 挖掘/移动加成
  - 蟹肉烤串 / 沙拉 / 三明治：便携型野外恢复

## 2. 基础蟹壳装备

### 2.1 蟹壳套装

- 蟹壳头盔（EQP-BASE-HELM）
- 蟹壳胸甲（EQP-BASE-CHEST）
- 蟹壳护腿（EQP-BASE-LEGS）
- 蟹壳靴子（EQP-BASE-BOOTS）

**定位**：略高于铁装的中期护甲，可作为进入 Boss 线之前的过渡套装。

### 2.2 蟹壳盾牌（EQP-BASE-SHIELD）

- 替代原版盾的中期选择
- 耐久略高，后续可升级为元素盾（与 Boss 套装联动）

### 2.3 蟹壳背包（EQP-BASE-BACKPACK）

- 仅螃蟹可装备
- 用于负重螃蟹系统（详见系统文档）

## 3. 五套 Boss 蟹壳甲

每套 4 件（头盔 / 胸甲 / 护腿 / 靴子），装备 ID 已在 Excel 中定义，这里描述效果定位。

### 3.1 寒霜壳甲（FROST）

- 主色：冰蓝
- 主打：控制 + 冰抗 + 反伤
- 效果建议： 
  - 免疫冻伤、粉雪影响
  - 雪地移动速度加成
  - 套装效果：周围敌人持续缓慢；被攻击时小概率冰冻攻击者

### 3.2 腐沼壳甲（VENOM）

- 主色：暗绿色 + 毒雾
- 主打：毒抗 + 沼泽回复
- 效果建议： 
  - 免疫中毒
  - 站在沼泽方块上缓慢回复生命
  - 套装效果：对中毒目标伤害提升

### 3.3 潮汐壳甲（TIDAL）

- 主色：青蓝 + 波纹
- 主打：水下机动性
- 效果建议： 
  - 水下呼吸
  - 游泳/潜水速度提升
  - 套装效果：潜水时获得夜视，冲刺时形成水浪击退周围敌人

### 3.4 炽焰壳甲（BLAZE）

- 主色：红橙 + 熔岩纹
- 主打：火焰免疫 + 输出
- 效果建议： 
  - 火焰 / 岩浆免疫
  - 套装效果：普通攻击附带燃烧效果，站在岩浆上不受损害、移动自然

### 3.5 回声壳甲（ECHO）

- 主色：深蓝 + 声波纹
- 主打：感知 + 反击
- 效果建议： 
  - 感知隐身/潜行生物（例如给予玩家方向提示或粒子标记）
  - 受击时释放小范围声波击退
  - 套装效果：血量过低时自动释放一次大范围声波爆破

## 4. 五把 Boss 武器

### 4.1 寒晶蟹矛（WP-FROST-SPEAR）

- 类型：长矛
- 定位：高伤 + 冰冻控制
- 效果： 
  - 攻击附带短暂冰冻与减速
  - 右键发射冰刺投射物（CD ~ 8s）

### 4.2 沼毒钳刃（WP-VENOM-BLADE）

- 类型：单手武器
- 定位：高 DOT（持续伤害）
- 效果： 
  - 攻击附带中毒 III
  - 右键喷射毒雾 AOE（CD ~ 12s）

### 4.3 潮击三叉钳（WP-TIDAL-TRIDENT）

- 类型：三叉戟
- 定位：水下 / 雨天强化
- 效果： 
  - 可投掷并返回
  - 雨天/水下攻击力提升显著
  - 命中时产生水浪击退目标

### 4.4 熔爪巨钳（WP-BLAZE-CLAW）

- 类型：重爪武器
- 定位：高爆发火焰输出
- 效果： 
  - 高基础伤害 + 燃烧 II
  - 右键释放沿地面爬行的火焰波（CD ~ 10s）

### 4.5 震荡钳刃（WP-ECHO-BLADE）

- 类型：巨剑
- 定位：终局武器
- 效果： 
  - 本模组中最高基础伤害
  - 少量概率“震晕”敌人 1 秒
  - 右键释放环状声波冲击（CD ~ 15s）
