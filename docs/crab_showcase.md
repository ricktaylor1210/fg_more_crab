# 螃蟹生物对外展示整理

本文用于统一整理所有螃蟹相关生物的对外展示特性，后续可据此制作图鉴、介绍页、宣传文案或玩家说明。

当前已整理内容：

- 普通螃蟹变体

不纳入对外展示的内部参考实体：

- `fg:fg_crab`
- `fg:fg_crab_help`
- `fg:fg_crab_aggressive`

上述 3 个实体仅作为开发参考原型，项目结束后计划删除。

## 普通螃蟹展示口径

对外展示时建议强调：

- 每种螃蟹都有明确生态环境。
- 每种螃蟹都有轻度行为差异。
- 每种螃蟹有不同驯服偏好。
- 掉落差异服务于探索和收集，不把普通螃蟹做成高压战斗单位。

当前普通螃蟹通用基础：

| 项目 | 说明 |
|---|---|
| 共同类型 | 普通生态螃蟹 |
| 基础用途 | 前期生态、食物来源、基础材料来源、未来驯服体系入口 |
| 通用掉落 | `fg:crab_claws` 生蟹肉、`fg:crab_shell_powder` 蟹壳碎片 |
| 通用表现 | 共用螃蟹模型、基础移动动画、攻击动画、受伤逃跑/反击状态机 |

## 1. 沙壳蟹

| 项目 | 内容 |
|---|---|
| 实体 ID | `fg:fg_crab_sandy` |
| 中文名 | 沙壳蟹 |
| 对外一句话 | 最常见的海滩螃蟹，是玩家认识螃蟹生态的第一站。 |
| 展示标签 | 默认海滩型、常见、标准掉落、基础驯服 |

### 生态定位

沙壳蟹主要出现在普通海滩、浅海岸、沙地、红沙和砾石区域。它是普通螃蟹体系里的基准类型，数量最多，群体规模也最大。

### 行为特性

- 默认偏谨慎。
- 受伤后优先进入逃跑状态。
- 连续受击或同群体受压时，有小概率触发群体反击。
- 行为强度保持在前期生物水平，适合作为玩家第一次接触的普通螃蟹。

### 驯服偏好

| 项目 | 内容 |
|---|---|
| 驯服道具 | `fish`、`salmon` |
| 驯服成功率 | 40% |
| 诱饵半径 | 8 |

展示说明：沙壳蟹是标准驯服难度，适合承担普通螃蟹驯服教学。

### 掉落倾向

| 掉落 | 数量 |
|---|---:|
| 生蟹肉 | 1 ~ 2 |
| 蟹壳碎片 | 0 ~ 1 |

## 2. 赤潮蟹

| 项目 | 内容 |
|---|---|
| 实体 ID | `fg:fg_crab_red_tide` |
| 中文名 | 赤潮蟹 |
| 对外一句话 | 脾气更大的红色海岸螃蟹，受惊后更容易带动同类反击。 |
| 展示标签 | 暖海岸、好斗、护群、壳粉偏高 |

### 生态定位

赤潮蟹偏向海岸、暖海岸、红沙和砾石区域，生成权重低于沙壳蟹。它用于给普通螃蟹生态加入轻度危险感。

### 行为特性

- 更容易获得 aggressive 攻击人格。
- 护群广播范围更大。
- 受伤后更容易保持警戒和反击。
- 不建议展示成强敌，应展示成“普通螃蟹里更不好惹的一种”。

- 战斗倾向仍然偏低，不是主动攻击型。

## 对外展示推荐排序

建议按玩家探索顺序展示：

1. 沙壳蟹：默认入门。
2. 蓝潮蟹：水边差异。
3. 赤潮蟹：轻度危险。
4. 霜壳蟹：寒冷地区替换。
5. 珊瑚蟹：暖海探索奖励。
6. 潮苔蟹：驯服友好。
7. 暮潮蟹：夜间稀有目标。

## 内部实现备注

- 当前展示文案只覆盖 7 个正式普通变体。
- 当前驯服偏好已在实体 JSON 中通过 `minecraft:tameable` 和 `minecraft:behavior.tempt` 表达。
- 当前掉落差异已拆成 7 张变体专属掉落表。
- `fg:crab_claws` 是生蟹肉掉落物，不作为驯服道具使用。
- 蟹肉棒、蟹肉寿司、蟹黄汤等自定义 food 不作为驯服道具。
- 当前驯服道具使用 Bedrock 内容物品 ID，例如 `fish`、`salmon`、`clownfish`、`rotten_flesh`、`dried_kelp`。
