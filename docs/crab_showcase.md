# 螃蟹生物对外展示整理

本文用于统一整理所有螃蟹相关生物的对外展示特性，后续可据此制作图鉴、介绍页、宣传文案或玩家说明。

当前已整理内容：

- 普通螃蟹变体
- 捕蟹笼品质与捕获行为
- 矿物螃蟹变体
- 海盗螃蟹变体
- Boss 蟹王 TASK-01~15 主线闭环

不纳入对外展示的内部参考实体：

- `fg:crab`
- `fg:crab_help`
- `fg:crab_aggressive`

上述 3 个实体仅作为开发参考原型 / 兼容实体，不纳入对外展示；是否删除取决于后续兼容需求。

## 普通螃蟹展示口径

对外展示时建议强调：

- 每种螃蟹都有明确生态环境。
- 每种螃蟹都有轻度行为差异。
- 每种螃蟹有不同驯服偏好。
- 掉落差异服务于探索和收集，不把普通螃蟹做成高压战斗单位。

当前普通螃蟹通用基础：

| 项目 | 说明 |
|---|---|
| 共同类型 | 普通生态螃蟹 |
| 基础用途 | 前期生态、食物来源、基础材料来源、未来驯服体系入口 |
| 通用掉落 | `fg:crab_claws` 生蟹肉、`fg:crab_shell_powder` 蟹壳碎片 |
| 通用表现 | 共用螃蟹模型、基础移动动画、攻击动画、受伤逃跑/反击状态机 |

## 1. 沙壳蟹

| 项目 | 内容 |
|---|---|
| 实体 ID | `fg:crab_sandy` |
| 中文名 | 沙壳蟹 |
| 对外一句话 | 最常见的海滩螃蟹，是玩家认识螃蟹生态的第一站。 |
| 展示标签 | 默认海滩型、常见、标准掉落、基础驯服 |

### 生态定位

沙壳蟹主要出现在普通海滩、浅海岸、沙地、红沙和砾石区域。它是普通螃蟹体系里的基准类型，数量最多，群体规模也最大。

### 行为特性

- 默认偏谨慎。
- 受伤后优先进入逃跑状态。
- 连续受击或同群体受压时，有小概率触发群体反击。
- 行为强度保持在前期生物水平，适合作为玩家第一次接触的普通螃蟹。

### 驯服偏好

| 项目 | 内容 |
|---|---|
| 驯服道具 | `fish`、`salmon`、`kelp` |
| 驯服成功率 | 40% |
| 诱饵半径 | 8 |

展示说明：沙壳蟹是标准驯服难度，适合承担普通螃蟹驯服教学。

### 掉落倾向

| 掉落 | 数量 |
|---|---:|
| 生蟹肉 | 1 ~ 2 |
| 蟹壳碎片 | 0 ~ 1 |

## 驯服与负重蟹展示口径

普通生态螃蟹驯服后进入轻量陪伴玩法。对外展示时建议强调：

- 驯服蟹会默认跟随玩家。
- 玩家可右键切换“跟随 / 待命”；待命状态下会留在原地，不再主动跟随。
- 未被玩家命名的驯服蟹会自动补对应变体默认名，避免打开背包时标题显示“未知”。
- 玩家可制作「蟹壳背包」，主人 Shift+手持背包右键已驯服普通蟹进行装备。
- 已装备背包的驯服蟹会显示背包模型，并提供 27 格原生容器。
- 已装备背包的驯服蟹可由主人 Shift+手持剪刀右键卸下背包；只有 27 格容器全空时才会卸下，背包会掉落回世界供玩家回收。

当前背包基础功能已实机可用：已接入背包物品、配方、装备 / 卸下、27 格原生容器、主人限制、非空库存禁止卸下和模型显示。已确认打开容器、放置物品、标题不显示“未知”、空包剪刀卸下和非空保护流程可用；区块卸载、死亡 / 维度切换和多人非主人边界仍需继续回归。

### 驯服后交互

| 交互 | 条件 | 当前效果 |
|---|---|---|
| 右键驯服蟹 | 已驯服且是主人，未潜行 | 在跟随 / 待命之间切换 |
| Shift+手持蟹壳背包右键 | 已驯服且是主人，未装备背包 | 消耗 1 个蟹壳背包，记录为已装备 |
| Shift+右键已装备背包的驯服蟹 | 已驯服且是主人，已装备背包 | 打开 27 格原生容器，标题显示螃蟹默认名或玩家自定义名 |
| Shift+手持剪刀右键已装备背包的驯服蟹 | 已驯服且是主人，已装备背包，27 格容器全空 | 卸下背包并掉落 1 个蟹壳背包 |
| Shift+手持剪刀右键非空背包蟹 | 已驯服且是主人，容器非空或读取失败 | 冒烟并阻止卸下，保护背包内物品 |

## 捕蟹笼展示口径

捕蟹笼用于把“打螃蟹获得材料”扩展为“布置海岸资源点，等待并领取收获”的轻量循环。

对外展示时建议强调：

- 捕蟹笼按材质分品质，品质越高等待越短、被破坏概率越低、产出越好。
- 捕蟹笼是可被放置的实体道具，成熟后会晃动提示可领取。
- 玩家可在等待期放置驯服食物作为诱饵，笼子上方会显示对应诱饵粒子。
- 捕蟹笼等待时留在放置位置，进入可收获状态后才启用浮力；可收获且在水中时会播放轻微晃动的 holding 表现。
- 捕蟹笼也能放在陆地，但陆地捕获概率只有水面 / 水中的 1/3。
- 螃蟹有概率弄坏捕蟹笼，坏掉后不会返还完整笼子，只掉落少量残料。
- 高级捕蟹笼不仅能获得蟹肉和蟹壳碎片，也有概率放出不同普通螃蟹变体。

### 捕蟹笼品质

| 品质 | 物品 / 实体 ID | 等待时间 | 被破坏概率 | 对外定位 |
|---|---|---:|---:|---|
| 普通 | `fg:crab_pots_ordinary` | 60 / 90 / 120 秒 | 8% | 入门捕蟹笼，低成本但不稳定。 |
| 铜制 | `fg:crab_pots_copper` | 50 / 75 / 100 秒 | 6% | 第一档升级，基础材料产出更稳定。 |
| 铁制 | `fg:crab_pots_iron` | 45 / 65 / 90 秒 | 4% | 中期实用型，有概率放出珊瑚蟹。 |
| 金制 | `fg:crab_pots_gold` | 40 / 60 / 80 秒 | 3% | 偏高收益型，有概率放出潮汐系螃蟹。 |
| 钻石 | `fg:crab_pots_diamond` | 30 / 45 / 60 秒 | 2% | 高级捕蟹笼，可接触更多稀有普通变体。 |

### 诱饵行为

玩家可在捕蟹笼等待期手持诱饵右键放置诱饵，放入后会消耗 1 个道具，并在笼子上方显示对应诱饵粒子图标。已经放过诱饵后，手持同一种诱饵不会再显示“放置诱饵”提示；手持另一种可用诱饵时可更换诱饵。捕蟹笼成熟后仍保留诱饵粒子，玩家领取后清空诱饵并重新开始等待。

当前可用诱饵全部来自普通螃蟹的驯服食物：

实际交互兼容当前物品 ID：鳕鱼同时接受 `fish` / `cod`，热带鱼同时接受 `clownfish` / `tropical_fish`。

| 诱饵 | 来源口径 | 表现 | 作用 |
|---|---|---|---|
| `fish` / `cod` 生鱼 | 沙壳蟹、蓝潮蟹、霜壳蟹驯服食物 | 蓝色小鱼粒子 | 提高“放出螃蟹”结算概率 |
| `salmon` 鲑鱼 | 沙壳蟹、赤潮蟹、蓝潮蟹、霜壳蟹驯服食物 | 红色鱼粒子 | 提高“放出螃蟹”结算概率 |

| 普通 | 8% | 92% |
| 铜制 | 6% | 94% |
| 铁制 | 4% | 96% |
| 金制 | 3% | 97% |
| 钻石 | 2% | 98% |

| 铜制 | 70% | 30% | 55% | 45% |
| 铁制 | 65% | 35% | 50% | 50% |
| 金制 | 60% | 40% | 45% | 55% |
| 钻石 | 55% | 45% | 40% | 60% |

### 破坏行为

捕蟹笼每次等待结束时先判定是否被螃蟹弄坏。

- 若被弄坏：捕蟹笼实体消失，掉落木棍、线、蟹壳碎片等残料。
- 若未被弄坏：进入可领取状态，播放晃动表现，玩家右键后结算捕获结果并重新开始等待。
- 品质越高越不容易被弄坏，体现笼体材料更耐用。
- 当前破坏概率已在“捕蟹笼概率”中列出。

## 矿物螃蟹展示口径

对外展示时建议强调：

- 矿物螃蟹出现在矿洞或下界环境，击杀后掉落对应矿物和蟹壳碎片。
- 矿物价值越高，生成权重越低，生命值和抗击退倾向越高。
- 矿物螃蟹会在附近寻找对应矿石，靠近后真实吃掉矿石方块，再进入短时间强化。

- 吃矿后会进入冷却，避免同一只矿物蟹连续吞矿破坏采矿节奏。

- 当前展示文案覆盖 7 个正式普通变体、9 个矿物变体、3 个海盗变体、5 档捕蟹笼和 5 个 Boss 蟹王。
- 当前驯服偏好已在实体 JSON 中通过 `minecraft:tameable` 和 `minecraft:behavior.tempt` 表达。
- 当前驯服蟹已接入主人限定的跟随 / 待命切换，蟹壳背包已接入装备 / 卸下 / 掉落回收 / 27 格原生容器 / 非空禁止卸下 / 背包模型显示，基础打开和标题表现已实机可用。
- 当前掉落差异已拆成 7 张变体专属掉落表。
- 当前蟹肉已有基础料理和 7 个功能料理用途。
- 当前蟹壳碎片已用于普通捕蟹笼、蟹壳背包、蟹壳盾牌和蟹壳四件套配方。
- 当前捕蟹笼按普通、铜、铁、金、钻石 5 档区分，具备等待、放置驯服食物诱饵、可领取、破坏和品质化产出行为。
- 当前矿物蟹按 9 个独立实体接入，每个矿种独立控制贴图、掉落、生成、基础属性和吃矿强化。
- 当前矿物蟹的“吃矿变强”由服务端 Python 扫描匹配矿石、筛选可站立接近点、推动实体靠近、删除矿石方块并触发对应 Buff。
- 铜 / 铁 / 钻晶 / 石英矿物蟹的防御强化通过受伤事件做真实减伤；金 / 红石矿物蟹的强化会切换短冷却攻击行为。
- 当前海盗蟹已接入主动敌对、受伤集结、偷窃物品、携物逃跑、死亡返还、结构附近补刷、脚本生成小型藏身处和少量藏宝图直掉。
- 海盗结构联动由服务端脚本扫描水边木质残骸、箱子、木桶和沙砾环境；没有现成残骸时，会在合适海岸低概率生成木板、木桶、箱子和掉落物组成的小型藏身处场景。
- 当前 5 个 Boss 蟹王已接入行为实体、客户端实体、血条、P2/P3 阶段、脚本主题技能、展示级 `.mcstructure` 巢穴 / 神庙资源、结构投放入口、首轮补给宝箱、3 天 Boss 重刷和掉落核心。
- 当前 Boss 核心可拆解为蟹壳碎片，也可制作 5 套 Boss 护甲和 5 把 Boss 武器；装备已有完整套装增益、受击反制、武器命中特效、右键主动技能、统一冷却、耐久消耗、粒子和原版音效命令。
- `fg:crab_claws` 是生蟹肉掉落物，不作为驯服道具使用。
- 蟹肉棒、蟹肉寿司、蟹黄汤等自定义 food 不作为驯服道具。
- 当前驯服道具使用 Bedrock 内容物品 ID，例如 `fish`、`salmon`、`clownfish`、`rotten_flesh`、`dried_kelp`、`kelp`。
- 背包死亡 / 维度切换 / 区块卸载保存边界、盾牌耐久 / 副手表现、护甲装备效果、Boss 技能 / 巢穴结构、宝箱 loot table 和 Boss 装备主动技能仍需要游戏内实测；结构谜题、终局事件、蟹卵养殖、潮汐入侵和元素盾牌仍未纳入本轮。
