## 1. V1.0 基础生态与系统

当前静态状态：

- 普通生态螃蟹、矿物螃蟹、海盗螃蟹和捕蟹笼已经进入可测试 MVP。
- 料理 / 配方、基础装备、负重背包、Boss 展示级结构入口、复杂阶段机制、宝箱经济和 Boss 装备链已有 TASK-01~15 主线静态闭环；负重背包基础功能已实机可用，盾牌手感、结构放置、Boss 技能与装备主动技能仍需游戏内验收。
- 下列状态基于仓库文件静态检查，不等同于完整游戏内验收。

### 1.1 生物基础

- **TASK-01 实现普通螃蟹实体与 AI**：MVP 已接入
  - 移动、基础攻击、掉落与动画
  - 当前正式普通生态为 7 个独立变体
- **TASK-02 实现矿物螃蟹**：MVP 已接入
  - 9 个独立矿物实体
  - 服务端脚本负责匹配矿石扫描、靠近、吃矿和类型化 Buff
  - 生成规则已按矿物类型拆分环境权重
- **TASK-03 实现海盗螃蟹**：MVP 已接入
  - 3 个职业实体
  - 服务端脚本负责偷窃、携物逃跑、击杀返还、逃跑状态回落、受伤集结和海岸藏身处补刷

已知差异记录：

- [P2] 海盗蟹击杀掉落采用混合口径：保留职业掉落，击杀有少量藏宝图直掉；主要藏宝图仍来自小型藏身处和 Boss 结构宝箱。

### 1.2 系统基础

- **TASK-04 驯服系统**：基础版已接入普通螃蟹链路
  - 成功率判定、主人绑定、粒子反馈
- **TASK-05 负重螃蟹背包系统**：基础功能已实机可用
  - 已接：蟹壳背包物品、配方、驯服蟹装备 / 卸下、掉落回收、27 格原生容器、主人限制、非空库存禁止卸下
  - 已确认：普通生物 `container` 容器可打开 27 格、可放置物品，标题不显示“未知”，空包剪刀卸下和非空保护可用
  - 待继续回归：区块卸载、死亡、维度切换后的库存保存和多人非主人边界
- **TASK-06 捕蟹笼系统**：实体版 MVP 已接入
  - 5 个品质、诱饵、定时捕获、收获、破坏概率
  - 可收获时在水中浮起，陆地捕获概率降低为水中的 1/3
  - 当前不是 Block + BlockEntity 方案

### 1.3 内容补全

- **TASK-07 食物与配方**：功能料理基础版已接入
  - 已接：蟹肉棒、烤蟹肉、清蒸螃蟹、香辣蟹钳、蟹肉寿司、蟹黄汤、椰香蟹汤、蟹肉炒饭、蟹肉三明治、蟹肉味噌汤
  - 待确认：全部料理效果、饱食度和平衡是否符合游戏内预期
- **TASK-08 基础装备**：基础装备功能版已接入，待游戏内确认
  - 已接：蟹壳背包、蟹壳盾牌、蟹壳四件套物品和配方
  - 已接：盾牌自定义盾牌入口、副手、抵挡角度、盾牌事件、潜行正面格挡兜底、减伤、冷却和耐久入口
  - 待确认：护甲装备栏、防御值、盾牌副手表现、动画和耐久写回

## 4. 建议开发顺序（简版）

1. 对 TASK-01 ~ 03 和 TASK-06 做游戏内验收与平衡回调。
2. 游戏内验收驯服蟹跟随 / 待命、背包长线保存边界、料理效果和新配方。
3. 游戏内验收基础护甲、蟹壳盾牌潜行正面格挡、副手表现和耐久写回。
4. 游戏内验收 5 个 Boss 的结构放置、生成、血条、P2/P3、主题技能、核心掉落和装备配方。
5. 继续观察背包 `container` 方案的死亡 / 维度切换 / 区块卸载 / 多人边界；本轮不自动回退到 `horse` 容器链路。
6. 根据验收调整 Boss 结构生成频率、临时方块持续时间、宝箱奖励和主动技能数值。
7. 后续扩展：结构谜题、终局事件、蟹卵养殖、潮汐入侵、元素盾牌和生态/事件/平衡微调。
