# 开发任务与版本规划

本文件对照 Excel 中 TASK-01 ~ TASK-15，作为开发顺序参考。

---

## 1. V1.0 基础生态与系统

### 1.1 生物基础

- **TASK-01 实现普通螃蟹实体与 AI** 
  - 移动、基础攻击、掉落与动画
- **TASK-02 实现矿物螃蟹** 
  - 多种矿物子类型
  - 吃矿行为与对应掉落
- **TASK-03 实现海盗螃蟹** 
  - 偷窃逻辑 + 逃跑 AI

### 1.2 系统基础

- **TASK-04 驯服系统** 
  - 成功率判定、主人绑定、粒子反馈
- **TASK-05 负重螃蟹背包系统** 
  - Menu + Screen + ItemStackHandler
- **TASK-06 捕蟹笼系统** 
  - Block + BlockEntity + 定时捕获逻辑

### 1.3 内容补全

- **TASK-07 食物与配方** 
  - 注册所有料理 + 配方
- **TASK-08 基础装备** 
  - 基础蟹壳装甲 + 蟹壳盾牌

3. TASK-07 ~ 08：食物与基础装备
4. TASK-09：Boss 框架
5. TASK-10 ~ 13：四大 Boss + 场景
6. TASK-15：Boss 掉落装备
