# 系统与机制设计

## 1. 驯服系统

### 1.1 适用对象

- 普通螃蟹（后转化为驯服螃蟹 / 负重螃蟹）
- 未来可扩展到其他蟹种（如沙滩蟹、珊瑚蟹等）

### 1.2 驯服流程

- 玩家手持食物右键未驯服螃蟹：
  - 消耗 1 个食物
  - 按食物类型判定成功率： 
    - 蟹肉棒：40%（可调）
    - 蟹肉寿司：80%
    - 蟹黄汤：90%
  - 成功： 
    - 绑定主人 UUID
    - 播放爱心粒子与音效
  - 失败： 
    - 螃蟹对玩家进行一次攻击（轻微伤害）
- 已驯服且是主人：
  - 普通右键：跟随 / 待命 切换
  - Shift+右键：打开负重蟹背包（若已装备）

## 2. 负重螃蟹背包系统

### 2.1 数据结构

- 蟹实体中新增字段： 
  - `has_backpack: boolean`
  - `backpack_item: ItemStack`
  - `crab_inventory: ItemStackHandler`（如 9 / 18 / 27 格）

### 2.2 装备 / 卸下流程

- 装备：
  - 条件：螃蟹已驯服，手持「蟹壳背包」，Shift+右键
  - 行为： 
    - `has_backpack = true`
    - `backpack_item` 存为当前物品
    - 玩家物品栏减 1 个背包
- 卸下：
  - 条件：螃蟹已装备背包，Shift+右键（空手或非背包）
  - 行为： 
    - 尝试将 `backpack_item` 放回玩家背包，否则掉落在地
    - `crab_inventory` 中所有物品掉落 / 尝试给玩家
    - `has_backpack = false`

### 2.3 背包界面

- 使用自定义 Menu + Screen 打开螃蟹背包菜单： 
  - 上部：螃蟹物品栏（9/18/27 格）
  - 下部：玩家背包 + 快捷栏

## 3. 捕蟹笼系统

### 3.1 捕蟹笼方块

- 方块 + BlockEntity： 
  - 状态： 
    - `has_catch: boolean`
    - `catch_type: enum { NONE, CRAB_ENTITY, LOOT_TABLE }`

### 3.2 Tick 逻辑（简化设计）

- 条件：捕蟹笼周围存在水（检查上下或四周）
- 每隔一段时间（可配置，如 5~10 分钟）：
  - 若 `has_catch == false`： 
    - 随机判定是否捕获成功
    - 成功时： 
      - 决定结果： 
        - 普通螃蟹实体
        - 蟹肉/蟹壳等物品
        - 少量垃圾（线、海带等）
      - 设置 `has_catch = true`，记录 `catch_type`
- 玩家右键捕蟹笼：
  - 若 `has_catch == true`： 
    - 发放捕获结果（生成实体或给予战利品）
    - 重置 `has_catch = false`

### 3.3 可扩展方向

- 高级捕蟹笼（铁/金/钻/远古）： 
  - 提高捕获率
  - 解锁矿物螃蟹、海盗螃蟹、Boss 幼体等
- 诱饵系统： 
  - 在捕蟹笼 UI 中放入不同食物，提高特定螃蟹捕获率

## 4. Boss 框架与阶段系统

### 4.1 抽象 Boss 基类

- `AbstractCrabBossEntity` 建议包含： 
  - 字段： 
    - `phase: int`（当前阶段，1/2/3）
    - `phase_timer: int`
  - 方法： 
    - `enterPhase(int phase)`
    - `tickPhaseBehavior()`
  - Boss 血条（BossBar）

### 4.2 通用阶段划分

- 阶段 1：100% ~ 70% HP
- 阶段 2：70% ~ 40% HP
- 阶段 3：40% ~ 0% HP

各 Boss 各阶段行为详见：`docs/04_worldgen_and_bosses.md#各-boss-阶段设计`
