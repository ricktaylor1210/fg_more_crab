# 更多螃蟹项目开发进度复核

复核日期：2026-07-28

## 1. 复核口径

本文件用于快速说明行为包侧当前进度。它不是历史归档，而是当前仓库状态的静态复核；整体完成度、实机证据、资源包风险和发布门禁统一以 `docs/project_progress_analysis.md` 为准。

边界：

- 仅基于仓库文件说明行为包实现，不把文件落盘等同于实机通过。
- 除背包基础流程已有用户回归记录外，其余主链路未形成完整实机结论。
- 不覆盖 `docs/` 下更完整的设计说明。
- 当前整体分层评估为：静态实现约 82%~86%，实机集成约 45%~55%，发布成熟度约 35%~45%。

### 2.2 捕蟹笼

当前捕蟹笼按实体版 MVP 落地：

- 普通、铜、铁、金、钻石 5 个品质。
- 鳕鱼、鲑鱼、热带鱼、腐肉、海带、干海带作为诱饵。
- 放置诱饵、替换诱饵、收获和收获后清空诱饵。
- 诱饵粒子、可收获晃动、水中可收获浮起和 holding 动画。
- 陆地捕获概率为水中概率的 1/3。
- 螃蟹低概率破坏笼子，品质越高概率越低。

状态：MVP 已接入。

注意：当前不是 BlockEntity / 容器 UI 方案，后续如需复杂诱饵槽位再升级。

- 蟹肉棒、烤蟹肉、清蒸螃蟹基础配方。

当前边界：

- 普通生物 `container` 容器基础功能已实机可用：27 格可打开、可放置物品，标题不再显示“未知”，空包剪刀卸下和非空保护流程可用。

## 4. 当前风险

- 多实体方案增加了跨文件维护成本，新增类型必须同步实体、生成、掉落、资源包入口、图集、语言和脚本映射。
- 矿物蟹、海盗蟹和捕蟹笼依赖服务端脚本，静态检查不能替代游戏内长时间测试。
- 当前获得材料的入口已经增加，基础消耗、Boss 结构入口和 Boss 装备链已补上，但中后期数值和平衡仍需实测。
- 配置指南仍以原型三蟹作为讲解样本，阅读时需要区分“样本实体”和“当前正式实体范围”。

## 5. 建议下一步

1. 先做游戏内验收：普通生态生成、捕蟹笼交互、矿物蟹吃矿、海盗蟹偷窃和返还。
2. 根据验收结果微调概率、生成密度、脚本 tick 成本和状态回落。
3. 游戏内验收蟹肉 / 蟹壳碎片用途，并继续回归背包保存边界、多人主人限制和跟随 / 待命切换。
4. 游戏内验收蟹壳盾牌副手 / 抵挡 / 兜底格挡、蟹壳护甲、Boss 结构放置 / 生成 / 技能 / 巢穴 / 装备链。
